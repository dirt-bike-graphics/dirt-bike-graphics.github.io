# Kit déco moto cross : compatibilité par moto

Quelles motos tout-terrain partagent les mêmes plastiques, et peuvent donc recevoir le même kit déco. 17 motos de référence de 11 marques : motocross, enduro et électrique.

## Comment lire le tableau

Ligne Honda : un kit fait pour la CRF450R 2025 va aussi sur les CRF450R et CRF250R de 2025 à 2026.

Non couvert : les plastiques adaptables (Acerbis, Polisport, UFO), qui suivent en général la forme d'origine sans que ce soit garanti, et les petites modifications en cours de millésime.
