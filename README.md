# Dirt Bike Graphics Fitment

Which dirt bikes share the same plastics, and so can run the same graphics kit.

Graphics kits are cut to the shape of the shrouds, side panels, fenders and number plates. When a manufacturer keeps the same plastics across model years, or across the 250 and 450 of the same family, one kit layout fits all of them. Shops list this as "fits 2025 to 2026 CRF250R / CRF450R" and so on, but the information is scattered across product pages. This repo collects it in one place.

## What is here

| File | What it holds |
|---|---|
| [FITMENT.md](FITMENT.md) | A readable table: one reference bike per row, with every model and year that shares its plastics |
| [fitment.json](fitment.json) | The same data as JSON, for scripts and tools |

17 reference bikes are covered, from Honda, Yamaha, KTM, Kawasaki, Husqvarna, GasGas, Suzuki, Beta, Triumph, Ducati and Stark. Motocross, enduro and electric.

## How to read it

Take the Honda row: the reference bike is the 2025 CRF450R, and the list says the 2025 and 2026 CRF450R and CRF250R share those plastics. A kit made for any of them lines up on the others.

Two things the table does not cover:

- Aftermarket plastics (Acerbis, Polisport, UFO and others) often follow the stock shape, but not always. Check the plastics brand before you print.
- Small mid-year changes, such as a revised airbox cover, are not tracked here.

## Using it

The data is free to use in your own tools, spreadsheets or posts. If you find a mistake or know a fitment that is missing, open an issue with the model, the years and where you saw it.
